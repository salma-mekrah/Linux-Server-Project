# Linux-Server-Project
Administration d’un serveur Linux (CentOS) : utilisateurs, permissions, services, firewallD, scripts Bash et configuration réseau.
📘 Linux Server Project – Administration CentOS

🔧 Description du projet

Ce projet a pour objectif d’administrer un serveur Linux (CentOS) en appliquant les bases de la gestion des utilisateurs, des permissions, des services et de la sécurité réseau.
Il permet aussi d’explorer la configuration de firewallD et la création de scripts Bash simples.

⸻

✔️ Tâches réalisées

👥 1. Gestion des utilisateurs et permissions
	•	Création d’utilisateurs et groupes
	•	Attribution des permissions (rwx)
	•	Utilisation des commandes : useradd, passwd, chmod, chown

🌐 2. Configuration réseau
	•	Affichage et modification de l’adresse IP
	•	Vérification de connectivité avec ping
	•	Gestion de l’interface via nmcli

🔥 3. firewallD
	•	Activation / désactivation des services
	•	Ajout des règles de sécurité
	•	Vérification du statut

⚙️ 4. Services Linux
	•	Démarrer / arrêter / vérifier un service
	•	Utilisation : systemctl

📜 5. Scripts Bash
	•	Création de scripts simples
	•	Exécution via bash script.sh

⸻

🧰 Compétences développées
	•	Linux Administration
	•	Bash scripting
	•	firewallD
	•	Gestion des services
	•	Réseau Linux (nmcli)
